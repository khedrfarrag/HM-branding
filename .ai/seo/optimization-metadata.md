## 1. Next.js Metadata API
* **Rule**: All public routing nodes MUST declare a metadata schema (static or generated dynamically).
* **Requirements**:
  * Titles must not exceed 60 characters; descriptions must stay under 160 characters.

## 2. JSON-LD Schema.org Structured Data
* **Rule**: Every landing or services page MUST embed valid JSON-LD schemas.
* **Requirements**:
  * Person, Organization, and Service schema types must match layout data exactly.

## 3. Heading Tree & HTML5 Structure
* **Rule**: Document pages MUST contain exactly one `<h1>` tag in a semantic layout.
* **Requirements**:
  * Structured HTML5 tags (`<article>`, `<section>`, `<nav>`) must dictate reading flow.

## 4. OpenGraph & Share Cards
* **Rule**: Public routes MUST export OpenGraph (OG) image paths, Twitter card formats, and localization tags.
* **Requirements**:
  * Shared images must be formatted correctly (1200x630px AVIF/WebP).
