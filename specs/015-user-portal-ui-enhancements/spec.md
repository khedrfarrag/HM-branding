# Feature Specification: User Portal UI Enhancements

**Feature Branch**: `015-user-portal-ui-enhancements`

**Created**: 2026-07-27

**Status**: Draft

**Input**: User description: "تحسين واجهة اليوزر بورتال — أولاً: تحديث الأرقام في سيكشن الإحصائيات لتكون واقعية وتقنع العميل. ثانياً: تحسين الخريطة اللوجستية الحية. ثالثاً: إضافة تأثيرات ظهور تدريجية (scroll transitions) لكل سيكشن."

## User Scenarios & Testing *(mandatory)*

### User Story 1 — Credible & Persuasive Statistics Section (Priority: P1)

زائر الموقع يصل إلى سيكشن الإحصائيات ويجد أرقاماً واقعية وموثوقة تعكس خبرة حسام مبروك الفعلية في التجارة الدولية — فتدفعه هذه الأرقام إلى الاقتناع باتخاذ إجراء (حجز استشارة أو التواصل).

**Why this priority**: الأرقام غير الواقعية تفقد المصداقية وتُقلل من تحويل الزوار. هذا هو الهدف التسويقي الأول.

**Independent Test**: فتح الصفحة الرئيسية → التمرير لسيكشن الإحصائيات → التحقق من أن الأرقام واقعية ومنطقية لخبير استيراد وتصدير دولي.

**Acceptance Scenarios**:

1. **Given** زائر يشاهد سيكشن الإحصائيات، **When** يقرأ الأرقام، **Then** يجب أن تكون منطقية ومقنعة (سنوات الخبرة ≤ 15، حجم التجارة بعشرات الملايين، الدول ≤ 35).
2. **Given** المستخدم يتصفح الموقع، **When** يصل للإحصائيات، **Then** تُعرض أرقام واقعية مصحوبة بتسميات واضحة باللغتين العربية والإنجليزية.
3. **Given** الصفحة محملة بالكامل، **When** تظهر الأرقام، **Then** لا يوجد أي رقم يبدو مبالغاً أو غير قابل للتصديق.

---

### User Story 2 — Enhanced Live Logistics Map Section (Priority: P1)

زائر الموقع يرى سيكشن الخريطة اللوجستية ويفهم رسالتها بوضوح — بدلاً من نص "مزامنة الاتصال" المبهم، يظهر محتوى إعلامي واضح يشرح الشبكة التجارية الدولية لحسام مبروك مع نقاط جغرافية بارزة.

**Why this priority**: الخريطة حالياً تُعرض فارغة مع نص غامض — مما يُشوه الانطباع الأول ويُضعف المصداقية.

**Independent Test**: فتح الصفحة الرئيسية → رؤية سيكشن الخريطة → التحقق من وجود محتوى ذي معنى وعدم ظهور "مزامنة الاتصال".

**Acceptance Scenarios**:

1. **Given** زائر يرى سيكشن الخريطة، **When** ينظر إلى المحتوى، **Then** لا يظهر نص "مزامنة الاتصال" أو أي نص تقني غير مفهوم.
2. **Given** الخريطة اللوجستية معروضة، **When** تحميل الصفحة، **Then** تُعرض نقاط جغرافية بارزة (الصين، الإمارات، مصر، أوروبا) مع تسميات واضحة.
3. **Given** المستخدم يقرأ سيكشن الخريطة، **When** يتصفح المحتوى المحيط، **Then** يجد عنواناً ووصفاً واضحاً يشرح الشبكة التجارية الدولية.

---

### User Story 3 — Scroll-Triggered Section Reveal Animations (Priority: P2)

عند تمرير المستخدم للأسفل، تظهر سيكشنات الصفحة تدريجياً بتأثيرات دخول سلسة — كل عنصر داخل السيكشن يظهر بتسلسل (stagger) بدلاً من ظهورهم مرة واحدة. مثال: سيكشن "بناء الجسور التجارية عبر السنوات" تظهر كل نقطة تاريخية واحدة تلو الأخرى.

**Why this priority**: التأثيرات تجعل الموقع راقياً ومتميزاً وتحافظ على انتباه المستخدم.

**Independent Test**: فتح الصفحة → التمرير ببطء → ملاحظة أن كل سيكشن يظهر بتأثير دخول عند وصوله للشاشة.

**Acceptance Scenarios**:

1. **Given** المستخدم يبدأ التمرير، **When** يصل أي سيكشن لمنطقة الرؤية، **Then** يظهر السيكشن بتأثير fade + translate سلس (مدة 300–600ms).
2. **Given** سيكشن يحتوي على عناصر متعددة، **When** يدخل الشاشة، **Then** تظهر العناصر تباعاً بفاصل زمني قصير بين كل عنصر (stagger).
3. **Given** المستخدم لم يمرر بعد، **When** الصفحة محملة، **Then** العناصر below-the-fold تبقى خفية حتى يتم التمرير إليها.
4. **Given** مستخدم يفضل `prefers-reduced-motion`، **When** يزور الصفحة، **Then** تظهر العناصر فوراً دون تأثيرات حركية.

---

### Edge Cases

- ماذا يحدث إذا كان المتصفح لا يدعم `IntersectionObserver`؟ → يُعرض المحتوى مرئياً فوراً دون تأثير.
- ماذا لو كان حجم الشاشة صغيراً والسيكشن يملأ الشاشة كاملاً؟ → يُفعَّل تأثير الظهور عند تحميل الصفحة لهذا السيكشن.
- ماذا لو لم تكن بيانات الخريطة الجغرافية متاحة؟ → تُعرض مناطق ثابتة مُدرجة يدوياً كـ fallback.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: يجب تحديث أرقام سيكشن الإحصائيات لتعكس قيماً واقعية لخبير استيراد وتصدير دولي بخبرة 10-15 سنة.
- **FR-002**: يجب إزالة نص "مزامنة الاتصال" من الخريطة اللوجستية واستبداله بمحتوى وصفي واضح.
- **FR-003**: يجب إضافة نقاط جغرافية بارزة للخريطة (الصين، الإمارات، مصر، أوروبا) مع تسميات وصفية.
- **FR-004**: يجب أن تظهر كل سيكشن في الصفحة الرئيسية بتأثير fade-in + slide-up عند دخولها منطقة الرؤية.
- **FR-005**: يجب أن تدعم تأثيرات الظهور التسلسلي (stagger) للعناصر المتعددة داخل نفس السيكشن.
- **FR-006**: يجب تعطيل تأثيرات الظهور تلقائياً لمستخدمي `prefers-reduced-motion`.
- **FR-007**: يجب أن تعمل التأثيرات على جميع الأجهزة (موبايل، تابلت، ديسك توب) دون تدهور في الأداء.
- **FR-008**: يجب أن يتم تأثير الظهور مرة واحدة فقط لكل سيكشن (لا تكرار عند العودة للأعلى).
- **FR-009**: يجب أن يكون المحتوى المحيط بالخريطة اللوجستية ثنائي اللغة (AR/EN).

### Key Entities

- **إحصائية (Statistic)**: رقم + تسمية + وحدة قياس + ترجمة AR/EN — ثابتة في الكود.
- **نقطة جغرافية (GeoPoint)**: اسم منطقة + دولة + موقع تقريبي على الخريطة — مُدرجة ثابتة.
- **تأثير ظهور (RevealAnimation)**: نوع (fade/slide) + مدة + تأخير + stagger interval.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: أرقام سيكشن الإحصائيات تقع ضمن نطاق واقعي ومقنع عند المراجعة البشرية.
- **SC-002**: سيكشن الخريطة اللوجستية لا يحتوي على أي نص تقني أو غامض بعد التحديث.
- **SC-003**: جميع سيكشنات الصفحة الرئيسية تظهر بتأثير ظهور عند التمرير على 100% من المتصفحات الحديثة.
- **SC-004**: تأثيرات الظهور تعمل بمعدل 60 إطار/ثانية على الأجهزة المحمولة.
- **SC-005**: مستخدمو `prefers-reduced-motion` يرون المحتوى فوراً دون أي تأخير.
- **SC-006**: بناء المشروع يكتمل بدون أي أخطاء TypeScript بعد التطبيق.

---

## Assumptions

- الأرقام الواقعية للإحصائيات تُحدَّد يدوياً بناءً على خلفية حسام مبروك (10-15 سنة خبرة، تجارة مع الصين وآسيا).
- الخريطة اللوجستية حالياً مبنية داخل مكون موجود في الكود ولا تعتمد على بيانات خارجية.
- تأثيرات الظهور تُنفَّذ باستخدام Framer Motion المتوفر في المشروع دون مكتبات إضافية.
- لا توجد متطلبات لتكامل الخريطة مع خدمة خرائط خارجية (Google Maps / Mapbox) في هذه الفيتشر.
- التأثيرات تُطبَّق على السيكشنات الموجودة في الصفحة الرئيسية فقط.
- يُستخدَم CSS transitions للتأثيرات الخفيفة وFramer Motion للتأثيرات التسلسلية المعقدة، وفق دستور المشروع.
